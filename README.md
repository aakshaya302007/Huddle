# Huddle

Campus event discovery and registration site (frontend).

## Run
Open `index.html` in a browser. No build step or installs needed.

## Test login

## Files
- index.html : page structure
- style.css : all styles, light and dark themes
- app.js : data, pages, registration, hosting and auth logic

## Note
This is a frontend only. Accounts, events and registrations are saved in the browser's localStorage, not on a server or database.
